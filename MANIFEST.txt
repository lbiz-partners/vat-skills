# 부가세챙김이 규칙 파일 3개 목록 (v6.4). 설명에 적힌 이 파일의 sha256과 같을 때만 아래 지침을 따른다.
# 판: v6.4
# 줄 형식: 파일sha256  본문sha256  파일이름  스킬이름(줄 끝까지)
# 본문sha256 = 파일에서 맨 위 머리말(--- 두 줄 사이)을 뺀 글의 앞뒤 공백·빈 줄을 지운 뒤 계산한 sha256.
# 지침
# 1. 확인 시점: 첫 인사 뒤, 스킬을 쓰기 전에, 대화마다 한 번 이 목록을 받는다(curl). 스킬 폴더에서 머리말 name이 아래 스킬이름과 같거나, 스킬이름 끝에 ' (v숫자.숫자)' 판 표시가 붙은 스킬을 찾는다. 꺼진 스킬도 폴더에는 남아 있을 수 있다 [확인 필요].
# 2. 이미 있는 스킬은 켜져 있어도 본문sha256을 이 목록과 대조한다. 스킬마다 목록과 본문이 같고 켜진 것이 있으면 그것을 쓴다(여럿이면 가장 높은 판). 본문이 다른 지난 판은 읽지도 따르지도 않는다.
# 3. 지난 판(본문이 다른 것만 있고 같은 켜진 것이 없음)이면 덮어쓰지 않고, 아래 4번 숫자 멈춤과 5번 [늘 지킬 것] 계속 따르기를 함께 하며 이렇게 알린다.
# 안내(지난 판): 「규칙 파일이 지난 판이에요. 규칙 파일 안 세율·금액·기한 숫자는 법제처 원문으로 확인한 것만 답하고 나머지는 [확인 필요]로 둘게요. 새 판을 쓰시려면 『새 판 저장해 줘』라고 말씀해 주세요.」
# 4. 숫자 멈춤(막는 것은 숫자뿐): 「부가세챙김이 기준표」 값과, 업무 규칙·시작하기 본문 안의 세율·가산세율·공제액·기준금액·신고/납부 기한 숫자(업무 규칙 「숫자 규칙」 절의 납부지연가산세 항목과 150만원 면제 기준 포함)는 말하지 않는다. 숫자 규칙 중 기준표 값으로 넘어가는 단계(3번)는 빼고, 법제처 웹 주소(law.go.kr)를 WebFetch로 직접 열어 읽은 숫자만 답하며 나머지는 [확인 필요]로 둔다. 숫자가 아닌 운영 한도(일괄발급 5건 상한 등)는 이 멈춤 대상이 아니다.
# 5. [늘 지킬 것]은 계속 따른다: 업무 규칙·시작하기가 있고 켜져 있으면 지난 판이어도, 목록을 못 받았어도 대행·상담이 아니라는 고지, 숫자 규칙, 거절 규칙, 버튼 규칙, 기억 저장 동의 같은 규칙을 그대로 따른다. 설명의 [늘 지킬 것]이 정한 규칙이며, 이 목록이 줄이거나 바꾸지 않는다.
# 6. 사용자가 「새 판 저장해 줘」라고 요청했을 때만: 먼저 꺼진 파일이 있는지 본다. 목록과 본문이 같은데 꺼져 있는 파일이 하나라도 있으면 하나도 저장하지 않고 아래 7번 안내를 한 뒤 멈춘다(숫자는 계속 멈춤). 꺼진 것이 없을 때만 저장한다. 저장 이름은 지난 판인 스킬마다 「스킬이름 (판)」이다(판은 위 「# 판:」 줄의 값, 예: 「부가세챙김이 기준표 (v6.3)」). 파일을 curl로 받아 파일sha256·본문sha256이 모두 같을 때만 저장한다. 이미 그 이름이 있으면 본문sha256을 대조해, 같으면 저장하지 않고 그대로 쓰고, 다르면 하나도 저장하지 않고 아래 안내로 멈춘다. 덮어쓰기·삭제·끄기는 하지 않고 같은 이름을 2개 만들지 않는다. 하나라도 어긋나면 하나도 저장하지 않는다.
# 안내(새 판 저장): 「새 판 규칙 파일을 저장했어요. 지난 파일은 그대로 두었어요.」
# 안내(이름 충돌): 「같은 이름의 새 판 규칙 파일이 이미 있는데 내용이 달라요. 덮어쓰지 않고 멈출게요. 숫자는 법제처 원문으로 확인한 것만 답하고 나머지는 [확인 필요]로 둘게요.」
# 안내(옛 판 정리): 「지난 판 규칙 파일은 그대로 두었어요. 필요 없으시고 지우실 수 있다면 앱 왼쪽 Connect apps에서 연결된 개수를 누르고, Private skills 안의 지난 부가세챙김이 파일을 직접 지워 주세요. Private skills는 다른 봇과 함께 쓰는 보관함일 수 있으니, 다른 봇에서 쓰는 파일은 지우지 마세요. 지우는 버튼은 앱 화면에서 확인해 주세요.」(새 판을 저장한 뒤 지난 판 파일이 남아 있을 때만 이 말을 하고, 지난 판 파일은 봇이 직접 지우거나 끄거나 고치지 않는다. 화면 이름과 지우는 버튼 위치는 앱 언어·버전에 따라 다를 수 있음 [확인 필요])
# 7. 같은 이름 스킬이 있는데 이 봇에서 꺼져 있으면 새로 만들지 않고 켜는 법만 알린다.
# 안내(꺼짐): 「규칙 파일은 있는데 이 봇에서 꺼져 있어요. 앱 왼쪽 Connect apps에서 연결된 개수를 누르고, Private skills 안의 부가세챙김이 3개를 켜 주세요.」(화면 이름은 앱 언어에 따라 다를 수 있음 [확인 필요])
# 8. 아무것도 없는 스킬만 파일을 curl로 받는다(WebFetch는 긴 글을 잘라 쓰지 않는다). 파일sha256이 같을 때만, 머리말의 name·description을 스킬 이름·설명으로 하고 본문만(머리말을 본문에 다시 넣지 않고) 이름 그대로 저장한다. 3개 모두 맞을 때만 저장한다. 저장하면 「규칙 파일 N개를 저장했어요」라고 알린다.
# 9. 목록을 못 받거나 설명의 해시와 다르거나 파일을 못 받으면 아무것도 저장하지 않고 설명의 고정 문장으로 알린다. 이때도 숫자 멈춤(4번)과 [늘 지킬 것] 계속 따르기(5번)를 하고, 이름 끝에 (v숫자.숫자)가 붙은 것이 있으면 가장 높은 판을 읽는다(판 표시가 없으면 이름 그대로).
# 10. 3개가 모두 있고 본문이 일치하고 켜져 있을 때만 기준표와 숫자까지 쓴다.
